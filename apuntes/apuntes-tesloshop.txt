🔷 react-router

En React, React Router es una biblioteca externa de terceros y por lo tanto, se instala como una dependencia en tu proyecto.
¿Para qué sirve?
React Router te permite simular la navegación de un sitio web tradicional de múltiples páginas dentro de una aplicación de React, sin recargar la página del navegador.
Con él puedes:
- Mostrar diferentes componentes según la URL actual (por ejemplo, / muestra el inicio y /contacto muestra el formulario de contacto).
- Manejar parámetros dinámicos en las URLs (como /productos/123).
- Crear rutas protegidas que requieren autenticación.

🔷 useRef
Es un Hook de react que te permite crear una referencia mutable que persiste durante todo el ciclo de vida del componente.
Este hook devuelve un objeto con una única propiedad llamada current (ej. miRef.current), la cual puedes leer y modificar libremente.
Para conectar el useRef con el elemento html tipo <Input, agregar al <Input la propiedad ref={nom_var_del_useRef}
A diferencia del estado (useState), actualizar un useRef no provoca un re-renderizado del componente.
-----

🔷 URLSearhParams
En JavaScript en general, URLSearchParams es una interfaz nativa del navegador que sirve para leer, crear y manipular los parámetros de consulta (query parameters) de una URL, es decir, todo lo que viene después del signo de interrogación (?) en una dirección web.
No es una característica exclusiva de React, pero se utiliza muchísimo en aplicaciones de React (junto con librerías como React Router o el hook nativo window.location) para gestionar el estado de la URL.
Cuando creas una instancia de URLSearchParams, esta retorna un objeto iterable (específicamente, un objeto de tipo URLSearchParams que actúa como un mapa o diccionario) que contiene todos los pares de clave-valor extraídos de la cadena de consulta de la URL.
A diferencia de un objeto de JavaScript tradicional ({}), este objeto no es un objeto plano, sino una estructura especial que viene con sus propios métodos integrados para consultar y modificar los datos.
🚨 A diferencia de useSearchParam, NO es reactivo por sí solo. Si la URL cambia, no re-renderiza tu componente automáticamente a menos que lo programes manualmente.

🔷 <Link ...> ... </ Link>
En React, específicamente cuando se usa la librería de enrutamiento React Router, el componente <Link> es el elemento estándar utilizado para navegar entre diferentes páginas o vistas de una aplicación de una sola página (SPA, por sus siglas en inglés).
A diferencia de la etiqueta HTML tradicional (<a>), <Link> permite cambiar de ruta sin necesidad de recargar la página completa.

<NavLink>: Es una versión especial de <Link> que sabe si la ruta actual está activa o no. Es sumamente útil para menús de navegación, ya que te permite añadir automáticamente una clase CSS (como active) al enlace en el que se encuentra el usuario actualmente.

----

🔷 useParams - (Parámetros de ruta)
Es un Hook de React Router que sirve para acceder a los parámetros dinámicos (segmentos de ruta) de la URL actual, dentro de una aplicación de React.
Cuando defines rutas dinámicas (por ejemplo, para mostrar el perfil de un usuario o los detalles de un producto), useParams te permite extraer fácilmente ese valor de la ruta para usarlo en tu componente (hacer una petición a una API, mostrar un título, etc.).

El hook useParams retorna un objeto JavaScript que contiene los pares clave-valor de los parámetros dinámicos de la URL actual.
Las claves corresponden a los nombres que definiste en la ruta precedidos por dos puntos :. Ejemplo: gender/:gender, clave = gender
Los valores son siempre cadenas de texto (strings) con lo que hayamos escrito realmente en la URL, valor = 'woman'

1. ¿Cómo se define la ruta?
En la configuración de tus rutas, marcas una sección de la URL como dinámica agregando dos puntos (:) antes del nombre del parámetro: /product/:idSlug
2. ¿Cómo se consume con useParams?
Dentro del componente que renderiza esa ruta, llamas a useParams(). Este devolverá un objeto con los pares clave-valor de los parámetros de la URL

🔷 cn

En el ecosistema de React (especialmente cuando se trabaja con Tailwind CSS y librerías populares como shadcn/ui), cn es una función utilitaria muy común que sirve para combinar, fusionar y gestionar clases de CSS de forma inteligente y condicional.
Su nombre viene de una abreviatura común para Class Name (nombre de clase).
La función cn no es una función nativa de React ni de JavaScript, sino que es la combinación de dos librerías externas muy potentes:
- clsx: Permite añadir clases de forma condicional (usando objetos, arrays o booleanos) sin complicarte con strings kilométricos. 
- tailwind-merge (twMerge): Resuelve los conflictos específicos de Tailwind CSS. Por ejemplo, si combinas px-2 y px-4, sabe que debe eliminar el primero y quedarse con el último.
Requiere importación con: import { cn } from "@/lib/utils";
¿Qué hace exactamente?
- Maneja condicionales limpiamente: Te permite activar o desactivar clases según el estado de tus variables o props.
- Elimina conflictos de Tailwind: Si un componente reutilizable ya trae un estilo por defecto (ej. bg-blue-500) y desde fuera le pasas otro (bg-red-500), cn se encarga de sobrescribirlo correctamente sin que Tailwind entre en conflicto o aplique estilos duplicados.
- Acepta múltiples formatos: Puedes pasarle strings, objetos condicionales o arrays indistintamente.

🔷 useLocation

El hook useLocation es una función incorporada en React Router (específicamente a partir de la versión 6) que sirve para obtener información sobre la URL actual en la que se encuentra el usuario dentro de una aplicación de una sola página (SPA).
Cada vez que cambia la ruta de la aplicación, este hook devuelve un objeto location actualizado que representa la ruta actual.
Propiedades del obj. location:
- pathname: (String) La ruta de la URL actual (por ejemplo, /productos o /contacto).
- search: (String) Los parámetros de consulta (query string) que van después del signo de interrogación (por ejemplo, ?id=5&sort=asc).
- hash: (String) El fragmento de la URL que empieza con # (por ejemplo, #seccion-2).
- state: (Any) Datos adicionales que se hayan pasado de forma oculta al navegar a través de la función navigate o del componente <Link>.
- key: (String) Un identificador único para esta ubicación específica.
